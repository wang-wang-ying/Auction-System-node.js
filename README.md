# Auction-System-node.js
# 拍卖系统（管理后台+用户前台）
拍卖平台是一套前后端分离的两端系统，包含后台管理端和前台用户端，用于拍卖商品管理、拍卖场次管理、竞价出价、成交结算、订单处理、保证金管理等业务的流程化运转。系统通过场次状态自动流转驱动拍卖进程，实现缴纳保证金、竞价出价、成交结算、订单付款发货的闭环管理。
### 1、系统功能

⭕ 后台管理端

· 登录

· 首页（数据统计大盘）

· 保证金管理：保证金记录 | 充值

· 用户管理：用户列表 | 冻结/解冻

· 订单管理：订单列表 | 发货 | 取消

· 成交管理：成交记录 | 确认成交

· 出价记录：竞价记录查询

· 拍卖场次管理：场次列表 | 新增/编辑/取消

· 商品分类管理：分类列表 | 新增/编辑/删除

· 商品管理：商品列表 | 商品审核 | 新增/编辑

· 系统管理：账号管理 | 角色管理 | 菜单管理

⭕前台用户端

· 登录 / 注册

· 首页

· 拍卖商品：商品列表 | 商品详情

· 拍卖场次：场次列表 | 场次详情（缴纳保证金 / 竞价出价）

· 用户中心：我的出价 | 我的订单 | 我的保证金

### 2、技术栈与工具
本项目采用稳定且广泛应用的技术栈，结合 Node 后端开发与 Vue 前端开发，确保开发流程清晰、系统稳定。

技术选型

· 后端：Node 20.19.6 + Express

· 数据库：MySQL 8.0

· 前端：Vue 3 + Element Plus

· 状态管理：Pinia

· 构建工具：Vite

· 开发工具：VSCode / WebStorm
